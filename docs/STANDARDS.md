# Поиск стандартов: /al

`/al фритюр` ищет все слова запроса на одной странице. Регистр и ё/е не учитываются.
Один результат отправляется фотографией, несколько — кнопками выбора (до 10).
Подпись содержит исходный документ и номер PDF-страницы. Поиск не генерирует ответы.
Используются только активные сотрудники и действующие администраторы; архивные
профили не получают доступ. Результат выбора принадлежит автору запроса и чату,
действует 10 минут. В группах бот должен получать сообщения-команды и иметь право
отправлять фотографии. Полнотекстовый поиск по сканам без текстового слоя не поддержан.

## Хранение

Репозиторий публичный. PDF, индекс и ключи в Git не попадают.
В release `ops-library-v1` хранится только AES-256-GCM зашифрованный ZIP,
ключ — в GitHub Actions secret `OPS_LIBRARY_KEY`. На runner архив расшифровывается
локально, строится SQLite-индекс. Исходные PDF не передаются внешнему поисковому ИИ.
Ключ доступен доверенным workflow репозитория; права записи workflow необходимо ограничивать.
Недоступность библиотеки не должна останавливать остальные функции бота.

Первоначальная загрузка оператором:

```
python standards_publish.py "path/to/library.zip" "path/to/gh"
```

Утилита создаёт секрет и release; не запускать повторно для обновления существующего
release: нужно версионировать архив и ключ согласованно. Файл ZIP должен быть доверенным.

Проверки: `python -m unittest discover -s tests`. Тесты проверяют поиск,
ограничение результатов, JPEG-рендеринг, запрет обхода путей, доступ и владение кнопками.
